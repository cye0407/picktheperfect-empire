Variety Selection Rules (Must Follow)

Balance the catalog

~25 mild/none (bells, poblanos, frying peppers, paprika types)

~35 medium/hot (jalapeño, serrano, cayenne, thai, etc.)

~30 very_hot/extreme (chinense-heavy: habanero/scotch bonnet/superhots)

~10 unusual/specialty (pubescens/rocoto, rare colors, ornamental, baccatum like aji)

Include famous + practical

Must include: Bell (California Wonder), Jalapeño, Serrano, Cayenne, Thai/Bird’s Eye, Habanero, Scotch Bonnet, Poblano/Ancho, Shishito, Padron, Anaheim, Hungarian Wax, Banana Pepper, Ghost Pepper (Bhut Jolokia), Carolina Reaper, Trinidad Scorpion, Aji Amarillo, Aji Lemon Drop, Rocoto.

Avoid junk entries

No “generic pepper” placeholders.

No duplicate varieties under different names unless you list the alt name.

Keep it picker-focused

Descriptions must help someone choose (taste + use + growing note), not history essays.

How to Assign Numeric Values (Critical)

You must convert qualitative descriptions into consistent numbers:

Heat

Use SHU ranges from reputable sources where possible.

If sources disagree, choose a reasonable range and set confidence=medium.

Flavor scales (1–10)

Use this rule-of-thumb mapping:

Sweetness

“sweet / fruity / candy-like” → 7–10

“balanced” → 4–6

“vegetal / sharp / not sweet” → 1–3

Fruitiness

chinense often higher (6–10) if described fruity/tropical

annuum usually lower unless described fruity

Smokiness

naturally smoky varieties (or commonly smoked/dried types) → 6–10

otherwise 1–3

Bitterness

only raise if sources mention bitter notes (5–8). Otherwise keep 1–4.

Earthiness

poblanos/ancho types often higher (5–8)

bright fresh chilis often lower (1–4)

Do not max everything. The dataset must have contrast or your scoring becomes useless.

Source Standards

For each pepper, include 2–4 sources (prefer official or recognized references):

Good source types:

University extension pages

Recognized seed catalogs (Johnny’s, Baker Creek, Seed Savers, Semillas, etc.)

Specialty pepper databases or well-known horticultural references

If you use forums/Reddit, only for flavor nuance and set confidence lower unless corroborated.

The sources field should look like:
johnnyseeds.com|chilepepperinstitute.org|rhs.org.uk

(Short names are fine; no raw URLs required.)
